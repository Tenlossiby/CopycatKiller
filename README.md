# CopycatKiller

> **Find text that's too close for comfort.**

CopycatKiller 是一个面向原创作者、编辑与内容工作者的作品相似性分析工具。它不只比较字面重复，也会先过滤通常不单独受著作权法保护的观点、事实、公共素材与常见表达，再检查可能具有独创性的具体文字、信息顺序、论证呈现、素材选择与编排、结构映射及异常一致线索。

- **在线版本**：https://copycatkillertenlo.netlify.app/
- **AI Skill**：[`SKILL.md`](./SKILL.md)
- **使用示例**：[`examples/usage-examples.md`](./examples/usage-examples.md)

## ⚠️ 法律参考声明

本项目仅用于辅助整理作品相似点、区分“思想/事实”与“可能受保护的具体表达”、梳理证据及生成维权材料初稿，**不构成法律意见、律师服务或对侵权成立与否的最终认定**。

著作权侵权是否成立，需要结合权利归属、作品独创性、接触可能性、可保护表达范围、实质性相似程度、合理使用及其他抗辩、证据真实性与完整性等因素综合判断。平台责任也需结合平台实际参与程度、是否收到合格通知、是否知道或应当知道侵权等具体事实判断。

工具输出可能存在遗漏或误判。涉及正式投诉、律师函、诉讼、索赔、公开指控或较大经济利益时，请咨询中国内地执业律师或其他具备相应资质的专业人士，并以现行有效法律法规、司法解释及主管机关或法院意见为准。

**请勿仅凭本项目输出公开认定他人“抄袭”“侵权”或要求平台、个人承担法律责任。**

## 能做什么

CopycatKiller 可以辅助：

- 过滤抽象观点、客观事实、公有领域内容、行业常识与常见表达；
- 对比原句、近似原句、同义替换、独特比喻与句式结构；
- 检查多个信息点的选择、排列顺序和前后连接；
- 比较论证中的铺垫、例证、转折、结论及具体呈现方式；
- 检查章节或段落是否存在打散、重排、重新拼接的对应关系；
- 标记相同错误、罕见译名、特殊截断等异常一致线索；
- 同时寻找共同来源、模板、行业惯例、独立创作等反向解释；
- 整理时间线、接触可能性、逐段对照表和来源映射表；
- 整理平台投诉所需材料，或生成供专业人士复核的中性材料初稿。

## 不做什么

CopycatKiller 不会：

- 用固定重复率或固定数量阈值直接判定侵权；
- 把“论证逻辑相似”自动等同于著作权侵权；
- 仅凭文风变化、平台推荐、流量或商业化直接认定责任；
- 冒充律师、法院、鉴定机构或保证维权结果；
- 在证据不足时补全事实；
- 帮助伪造、篡改或诱导形成证据；
- 生成用于威胁、骚扰、人肉搜索或煽动网暴的内容。

## 适用内容

主要适用于以文字表达为主的作品，例如：

- 图文笔记；
- 公众号文章；
- 知乎回答；
- 微博长文；
- 视频口播稿、播客稿；
- 评论、科普、知识型内容；
- 小说、故事、脚本；
- 其他网络文字作品。

对于图片、美术作品、音乐、视频画面、软件、游戏规则或复杂产品界面，只能进行有限的线索整理。

## 安装 Skill

支持 Agent Skill / `SKILL.md` 的工具可直接使用仓库中的 [`SKILL.md`](./SKILL.md)。

最简目录结构：

```text
CopycatKiller/
└── SKILL.md
```

也可以下载整个仓库后，将 `SKILL.md` 放入目标工具要求的 Skill 目录。

## 开始使用

最好同时提供两份作品及基本信息：

```text
【作品 A】
标题：
作者：
发布时间：
发布平台：
正文：

【作品 B】
标题：
作者：
发布时间：
发布平台：
正文：

【补充情况】
双方是否有过接触：
是否使用相同公开资料：
希望得到的结果：
```

然后可以直接说：

> 第一篇是我的原创作品，第二篇是我怀疑存在洗稿的作品。请先过滤双方共同使用的事实、观点和公共素材，再比较可能具有独创性的具体表达；同时列出支持和削弱侵权主张的证据，不要直接替代法律认定。

更多可复制示例见 [`examples/usage-examples.md`](./examples/usage-examples.md)。

## 输出通常包含

1. 法律参考声明；
2. 已有材料、缺失材料与待核实事实；
3. 时间线与接触可能性；
4. 可保护表达过滤表；
5. 原文逐段对照表；
6. 结构或来源映射；
7. 反向证据与其他可能解释；
8. 分级相似性评估；
9. 下一步材料整理选项。
